### 4.3 现有接口需扩展的语义

1. **`X-Tab-Id` 请求头**：所有已认证接口读取并参与会话计数、强制下线、审计来源记录（CR 7.2 / 3.8）。
2. **统一错误响应**：`{ code, trace_id, message }`；401 = 会话失效、403 = 无权限、429 = 限流；不得返回堆栈 / SQL / 路径（CR 3.7）。
3. **RBAC 能力点**与 `src/constants/permission.ts` 对齐：`account:manage`、`role:read`、`audit:read`、`audit:export`、`param:write`、`device:control`、`device:upgrade`、`cert:manage`、`backup:manage`、`decommission`、`maintenance:enter`（CR 2.01 / 2.01 RE(2)）。
4. **登录失败语义**：`/permission/login` 的 401 仅表示凭据错误，不得触发前端会话过期逻辑（前端已按 URL 区分）。
5. **审计导出**：导出接口自身写审计（用户、时间、筛选条件、行数、结果），并限制普通用户删除/修改（CR 3.9 / 6.1）。
6. **参数接口服务端校验**：`/api/paraConfig/modifyParams`、`/api/ini/update`、`/network/set_ip` 需做 Schema / 范围 / 冲突校验（CR 3.5）。

## 6. 推进顺序建议

1. **解锁登录与认证现场**
   `session_token`、`/permission/logout`、`/permission/verify`、失败计数/锁定字段、`X-Tab-Id`、403/429 语义。
   完成后删除前端 `VITE_AUTH_TOKEN_FALLBACK`。
2. **审计闭环**
   `/api/history/status`、审计字段扩展、导出写审计、`audit:read/export` 角色确认。
3. **安全中心点亮**
   口令策略、证书、密钥、安全状态、网络规则、备份/恢复/退役、组件清单。
4. **补前端剩余约 2 人日**
   对端状态、Banner 下发、校验覆盖、资源仪表、证书状态条、配置摘要/升级预检接口接入、死代码清理。
5. **认证前收尾**
   CSP 收紧（i18n 预编译）、HTTPS 强制（部署层 / ZLG）、取证截图与审计记录归档。

## 8. 结论

- **前端**：4-2 的 11 个模块主干已完成，31 项自动化核验全部通过，`type-check` 与生产构建通过；剩余约 2 人日（校验覆盖、资源仪表、状态展示）及联调。
