# Modbus TLS 桌面客户端与服务端

Windows 一键打包与 EXE 使用步骤见 [WINDOWS.md](WINDOWS.md)。构建机双击 `build_windows.bat`，生成 `dist/ModbusTLS.exe`；目标电脑无需安装 Python 或 OpenSSL。在 Linux 开发机运行 `python3 -m tools.modbus_gui.prepare_windows` 可生成不包含用户证书与私钥的构建源码包。

独立工具，使用 Python 标准库 Tkinter 和 ssl，不依赖 Flask、设备数据库或 OP-TEE。支持 TLS 1.2 及以上、双向证书认证、公开证书导入/导出、证书信息查看和一键生成联调证书。

## 启动

在仓库根目录运行：

```bash
# 客户端窗口
python3 -m tools.modbus_gui --role client

# 服务端窗口（也可在同一窗口内切换两个页签）
python3 -m tools.modbus_gui --role server
```

源码运行需要 Python 3.8+ 与桌面环境。Ubuntu 如缺少 Tkinter，安装 `sudo apt install python3-tk`；查看和生成证书使用 OpenSSL 1.1.1+，通过 `openssl version` 检查，Linux 源码运行无需第三方 Python 包。Windows 推荐 Python 3.12 x64 并启用 Tcl/Tk，源码运行时需安装 cryptography；EXE 打包脚本会自动安装并内置所需依赖，目标电脑无需安装 Python 或 OpenSSL。

## 本机快速联调

1. 打开「证书管理 / 快速联调」，SAN 保持 `127.0.0.1`，点击「生成联调证书并配置两端」，选择保存目录。程序在其中新建唯一子目录，不覆盖旧证书。
2. 打开「服务端」，保持监听 `127.0.0.1:18020`、站号 1，点击「启动服务端」。
3. 在服务端寄存器操作中填写起始地址 `0`、写入值 `123, 456`，点击「设置本地寄存器值」。
4. 打开「客户端」，选择 `03 保持寄存器`、地址 `0`、数量 `2`，点击「发送请求」，结果为 `123, 456`。
5. 选择功能 `06` 或 `16` 可写入服务端保持寄存器。写入数量由「写入值」个数决定；06 只能提供一个值。服务端点击「刷新寄存器」可查看结果。

两个窗口分别运行时，生成证书的窗口会自动配置两端；另一个窗口须手动导入同一生成目录内对应的身份证书、私钥及对端公开证书。

## 连接现有 EMS 设备（trust-add）

默认勾选「EMS 设备模式」，生成 RSA-3072 直接自签证书，显式设置 `CA:FALSE` 和对应 `clientAuth` / `serverAuth` 用途，扩展配置与设备 TA 身份一致。客户端信任 `server.crt`，GUI 服务端信任 `client.crt`。此模式没有 `ca.crt` / `ca.key`。

设备脚本只接受直接自签客户端证书；旧版本 GUI 生成的 CA 签发 `client.crt` 不能用于设备 `trust-add`。需使用更新后的 GUI 勾选设备模式重新生成，把新的 `client.crt` 传到设备 `/tmp/client.crt`，再执行：

```bash
python app/script/modbus_certs.py trust-add --cert /tmp/client.crt
sudo systemctl restart tems
```

重启会中断现有设备通信，请在允许中断时操作。GUI 客户端使用新生成的 `client.crt` 与配套 `client.key`；从设备取得实际服务端公开证书（默认 `/etc/ems/modbus/slave.crt`），导入客户端「可信 CA / 对端自签证书」。不要把 GUI 模拟服务端的 `server.crt` 当作实际设备证书。目标填写设备实际 IP / 端口，名称验证必须匹配设备证书 SAN。私钥留在 GUI 客户端，不上传设备。

## 证书与跨机器连接

| 文件 | 用途 |
| --- | --- |
| `ca.crt` | 仅取消设备模式后生成，两端导入「可信 CA」 |
| `server.crt`、`server.key` | 服务端身份证书与私钥 |
| `client.crt`、`client.key` | 客户端身份证书与私钥 |
| `ca.key` | 仅取消设备模式后生成，CA 签发私钥不分发给对端 |

「导入」选择本地文件并引用其路径，不复制到系统证书库，不修改设备已有证书。支持 PEM 身份证书、PEM 私钥（可带密码）及 PEM CA 证书链。证书与私钥在连接/启动时校验；DER、PFX/P12 需要先转为 PEM。「导出」仅输出公开证书或 CA 证书链，拒绝包含私钥的文件；私钥需要由使用者安全转移至对应机器。

跨机器使用时，生成证书的 SAN 填写服务端实际 IP / DNS，服务端监听地址改为其网卡 IPv4 或 `0.0.0.0`，客户端目标填写服务端实际地址。`0.0.0.0` 仅用于监听。防火墙应允许所选 TCP 端口。若通过其他地址转发连接，可在客户端「验证服务端名称」中填写证书 SAN 内的 IP / DNS；留空则验证连接目标。

默认启用双向认证：客户端勾选「发送客户端证书」和「验证服务端证书」，服务端勾选「验证客户端证书」。这些选项可独立设置：

- 客户端取消「验证服务端证书」：跳过服务端证书链、有效期及 IP/DNS 名称校验，不读取信任栏文件，仍使用 TLS 加密。可以继续勾选「发送客户端证书」，满足现有 EMS 设备只验证客户端身份的通信方式。日志显示「未验证服务端证书及名称」。此模式不确认服务端身份。
- 服务端取消「验证客户端证书」：不要求客户端证书，无需配置信任栏。修改后停止并重启监听生效。
- 客户端取消「发送客户端证书」：不加载客户端证书及私钥。对端要求客户端证书时仍会拒绝连接。

TLS 设置修改对下一次客户端请求生效；服务端须停止后重新启动。

生成证书有效期为 365 天，包含未加密的 RSA 私钥，仅供联调；生成目录在支持权限控制的系统上设为 0700、私钥为 0600。也可导入已有证书。直接自签的对端身份证书可以放入信任栏，但是否可作为信任锚由本机 OpenSSL 版本和证书扩展决定。

## 协议范围与运行行为

客户端「寄存器操作」下方提供「循环间隔（毫秒）」「开始循环」「停止循环」和计数显示。默认间隔 1000 毫秒，可设置 10～3600000 毫秒。开始时保存当前连接、证书及寄存器参数，立即发送一次；每次请求完成或失败后等待所设间隔，再发送下一次。同一时刻只有一个请求，循环期间禁用单次发送与重复启动；修改参数需停止后重新开始。读取和写入功能均可循环，写入会重复发送启动时指定的值。

循环失败记录到日志和失败计数，不连续弹窗，随后按间隔重试。「停止循环」取消后续发送；已经发出的请求等待完成或所设超时后结束，等待期间不能再次启动发送。关闭窗口也停止后续循环。每条 TX/RX 报文均包含 `YYYY-MM-DD HH:MM:SS.mmm` 时间戳，使用运行电脑的本地时间，在收发回调时记录，而非在 GUI 刷新时记录。

- 功能码：03 读保持寄存器、04 读输入寄存器、06 写单个保持寄存器、16（十进制，0x10）写多个保持寄存器。参考 [Modbus 官方协议规范](https://modbus.org/docs/Modbus_Application_Protocol_V1_1b3.pdf)。
- 地址使用协议零起始地址 0～65535，40001 编号对应地址 0。值为无符号 16 位整数，支持十进制和 `0x` 前缀；读取最多 125 个，批量写入最多 123 个。
- 服务端保持寄存器与输入寄存器各有 65536 个，初值全为 0，界面可分别修改。仅配置的 Unit ID 会被响应。数据在程序内存中保存，停止再启动监听会保留，退出程序后丢失。
- 客户端每次请求新建 TLS 连接；超时可设为大于 0 且不超过 120 秒。服务端支持最多 32 个并发连接，每个连接握手/收包超时 5 秒。
- GUI 日志显示毫秒时间、收发方向、客户端/服务端与对端地址、完整 ADU 十六进制（MBAP + PDU）、事务号、协议号、长度、站号、功能码，以及请求地址/数量、响应寄存器值或异常码。收发报文均取自实际发送/接收的应用层字节；显示的是 TLS 加密前/解密后的 Modbus 数据，不包含 TCP/IP 头或 TLS 密文记录。最大长度报文也完整显示，长行自动换行。保留最近约 1500 行日志。工具不访问或控制本仓库的实际设备服务。
- 此工具始终使用 TLS，不提供明文 TCP、串口 RTU 或完整 Modbus Security 角色授权功能。连接现有 EMS 时，需满足其客户端身份信任策略；客户端默认校验服务端身份，也可按上述选项关闭校验。

## 验证

完整 TX/RX 报文位于窗口下方的独立日志区：TX 蓝色表示本端发送，RX 绿色表示本端接收，每条均包含完整 ADU 十六进制。上下区域之间的分隔条可拖动调整高度，日志区保留最小高度；上方配置内容可使用右侧滚动条查看。日志只读，支持鼠标选择后 Ctrl+C、Ctrl+A 全选（macOS 使用 Command），右键菜单可复制所选、全选或复制全部；工具栏「复制全部」可直接复制当前全部日志。「清空日志」清除当前显示。

在仓库根目录运行，测试仅使用本机回环地址的临时端口与临时证书目录：

```bash
python3 -m unittest tools.modbus_gui.test_modbus -v
# 另有隐藏窗口 GUI 集成测试，需要有效的桌面 DISPLAY
python3 -m unittest tools.modbus_gui.test_gui -v
```

覆盖真实 TLS 读写、并发、错误 CA/名称/客户端身份拒绝、单向认证、证书导出再导入、报文边界及停止后重用端口。GUI 测试通过界面回调完成证书生成、服务端启动、客户端读写与停止/重启。
