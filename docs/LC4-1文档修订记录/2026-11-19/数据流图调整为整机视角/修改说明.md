# 整机数据流图修订

移除音视频行；图内不出现LC，保留无表头的箭头式数据流。7类数据流采用整机逻辑视角，不以单个控制器的实现代表全部部件。配套文字清单、C节及EV02引用同步更新；其他安全能力的LC／PCS责任分工不变。

DF01｜账号／会话：管理员创建账号，操作及维护人员提交登录信息，由相应设备的账号管理和身份认证功能处理；账号记录保存至对应设备，认证结果及适用的会话信息返回使用人员。具体认证机制由相应部件人员确认。

DF02｜日志：一体机各部件的运行、告警、操作及维护活动产生记录，由对应日志功能保存至相应部件或接入的监控端；维护人员按实际权限查询或导出，导出件保存至维护终端。不假设整机已具备统一集中日志系统。

DF03｜证书及身份密钥：证书由签发机构签发，身份密钥按实际方案由设备或授权工具生成；相应部件的证书及通信功能配置、保存并使用这些材料，向通信对端提供公开证书用于身份校验。各部件是否使用证书及其私钥保护方式分别确认。

DF04｜备份及其密钥：具备备份功能的部件提供其可备份配置、账号等数据，由相应备份功能生成文件，交付本地存储或维护终端；具备加密备份功能时，其密钥由对应部件生成、派生或按实际方案提供，在对应的受控位置保存或使用，不据此认定全部部件均支持加密备份。

DF05｜配置：授权人员提交运行或通信参数，厂家／集成商提供配置基线，由整机管理入口或目标部件配置功能处理；配置写入相应控制器或设备，处理结果和状态反馈至操作／维护端。

DF06｜更新包：厂家或部件供应商制作更新文件，授权维护人员通过相应维护路径交付，由目标部件的软件更新功能处理并安装；版本、进度及结果返回维护终端。各部件的签名校验、权限和恢复机制由对应人员填写。

DF07｜运行及控制数据：外部EMS／调度产生指令，整机各控制器及采集设备产生运行数据；经整机通信、监控及控制功能处理后，指令传至相关执行部件，运行状态和告警送至监控端及EMS。内部交互与跨整机边界的数据流分别识别。

ZIP、XML、批注保留及其他文件条目一致性检查通过。
